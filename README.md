# DepthBench Website

Project page for **DepthBench: Measuring How Residual Connections Enable More Computational Depth**.

- Live site: https://keyu-wang-2002.github.io/DepthBench-Website/
- Paper: https://arxiv.org/abs/2609.32534
- Code: https://github.com/keyu-wang-2002/DepthBench
- Checkpoints: https://huggingface.co/aspect-ratio-scaling

A static site (`index.html`, `styles.css`, `site.js`, `assets/`) — no build step. To preview locally:

```bash
python3 -m http.server 8000
```
